# MC Host v2.9

মাইনক্রাফট (mineflayer) বট হোস্ট করার প্যানেল: ওয়েব ড্যাশবোর্ড + টেলিগ্রাম কন্ট্রোল + Mistral AI সহায়ক।
Wispbyte, Render বা যেকোনো Node.js হোস্টে চলে।

## Wispbyte-এ চালু করার ধাপ
1. Wispbyte client panel-এ আপনার সার্ভার খুলুন এবং সার্ভার পেজে দেখানো **পোর্ট** (যেমন 11336) নোট করুন।
2. এই ফোল্ডারের সব ফাইল সার্ভারে আপলোড করুন (বা Git repo থেকে নিন)। `node_modules` ও `data` আপলোড করবেন না।
3. Startup/Main file: `index.js` (অথবা কমান্ড `npm start`)। Node 18+ লাগবে। প্রথমবার `npm install` চালান।
4. Environment/Variables-এ দিন: `ADMIN_PASSWORD`, প্রয়োজনে `PORT` (প্যানেলে দেখানো পোর্ট), `MISTRAL_API_KEY`, `TELEGRAM_BOT_TOKEN`, `OWNER_ID`।
5. সার্ভার চালু করুন। কনসোলে `চালু: http://0.0.0.0:<পোর্ট>` দেখলে ঠিক আছে। Wispbyte পেজ রিফ্রেশ দিলে "running" দেখাবে।
6. ব্রাউজারে Wispbyte-এর দেওয়া ঠিকানা (IP:পোর্ট) খুলে পাসওয়ার্ড দিয়ে ঢুকুন।

পোর্ট নিয়ম: `PORT` > `SERVER_PORT` > `APP_PORT` > ডিফল্ট 11336। সার্ভার সবসময় `0.0.0.0`-এ শোনে (127.0.0.1 নয়)।
`ADMIN_PASSWORD` না দিলে প্রথমবার কনসোলে একটি পাসওয়ার্ড ছাপা হয়।

## Render-এ
`render.yaml` ব্যবহার করুন। ফ্রি প্ল্যানে ১৫ মিনিট নিষ্ক্রিয়তায় ঘুমিয়ে যায়: UptimeRobot দিয়ে `/healthz` প্রতি ৫ মিনিটে পিং করুন।
ফাইল মুছে গেলে বট ফেরাতে Upstash Redis (`UPSTASH_REDIS_REST_URL` / `_TOKEN`) দিন।

## Mistral AI
ড্যাশবোর্ড > সেটিংস থেকে API key দিন ও মডেল বাছুন (লিস্ট লাইভ লোড হয়)। কী করে:
- টেলিগ্রামে বটের পেজ > "AI দিয়ে স্ক্রিপ্ট আপডেট": সাধারণ ভাষায় বলুন, AI বটের লগ, বর্তমান স্ক্রিপ্ট ও আগের কথা মনে রেখে নতুন স্ক্রিপ্ট দেয়।
- কোড সিনট্যাক্স যাচাই হয়, তারপর "প্রয়োগ করুন" চাপলে সেভ হয়ে বট রিস্টার্ট হয় (আগের সংস্করণ রোলব্যাকে থাকে)।
- অফলাইন নোটিফিকেশনে "AI দিয়ে বিশ্লেষণ" বোতাম আছে। ওয়েব ড্যাশবোর্ডের AI পেজেও একই চ্যাট।
- AI মেমরি: প্রতি বটের আলাদা কথোপকথন ও সারাংশ নোট। মুছতে "মেমরি মুছুন"।

## টেলিগ্রাম
টোকেন ড্যাশবোর্ডের টেলিগ্রাম পেজ বা `TELEGRAM_BOT_TOKEN` env-এ দিন, তারপর বটকে /start দিন। প্রথম যিনি /start দেবেন তিনি মালিক (বা `OWNER_ID` দিন)।

## v2.2: Workers পেজ (Cloudflare Workers-এর মতো) ও বটের নতুন ফিচার
### Workers
- নতুন "Workers" পেজ: worker.js আপলোড (বা টেমপ্লেট/পেস্ট) > ডিপ্লয় > পাবলিক URL `https://আপনার-হোস্ট/w/<নাম>/...` (লগইন লাগে না)।
- ফরম্যাট: `export default { async fetch(request, env, ctx) {...}, async scheduled(event, env, ctx) {...} }` অথবা `addEventListener('fetch', e => e.respondWith(...))`। CommonJS (`module.exports = { fetch }`) ও চলে।
- ENV ভেরিয়েবল: কোডে `env.KEY` (বা `process.env.KEY`)। "গোপন" দিলে ভ্যালু আর প্যানেলে দেখা যায় না। বদলালে Worker নিজে রিস্টার্ট হয়।
- `env.KV`: সরল স্থায়ী key-value (get/put/delete/list, expirationTtl সহ, সর্বোচ্চ ৫০০০ key)।
- Cron: সেটিংসে মিনিট দিলে `scheduled()` চলে।
- ড্যাশবোর্ড: আজকের রিকোয়েস্ট, গতকাল, ৭/৩০ দিন, ত্রুটি (5xx) ও ত্রুটির হার, গড় লেটেন্সি, p50/p95, গত ২৪ ঘণ্টা ও ১৪ দিনের চার্ট, স্ট্যাটাস কোড ভাগ, সাম্প্রতিক রিকোয়েস্ট তালিকা। "আজ" আপনার ব্রাউজারের টাইমজোন অনুযায়ী গোনা হয়।
- নিরাপদ ডিপ্লয়: নতুন কোড লোড না হলে আগের কোডই চালু থাকে, আর "আগের সংস্করণ" বোতামে রোলব্যাক যায়।
- টেস্ট ট্যাব (মেথড, হেডার, বডি পাঠিয়ে উত্তর দেখুন), লাইভ console লগ, ক্র্যাশ হলে অটো-রিস্টার্ট, ৩০ সেকেন্ডে উত্তর না দিলে 504।
- প্রতিটি Worker আলাদা প্রসেস (মেমরি `WORKER_HEAP_MB`, ডিফল্ট 128)। সীমা `MAX_WORKERS` (১০)। রিকোয়েস্ট বডি ও রেসপন্স যথাক্রমে ১MB ও ৫MB পর্যন্ত। Worker কোডকে বিশ্বাসযোগ্য ধরা হয় (বটের স্ক্রিপ্টের মতোই), তাই শুধু নিজের কোড আপলোড করুন।
- স্ট্যাটাস `data/workers/` ফোল্ডারে থাকে। হোস্টের ফাইল মুছে গেলে কাউন্টার শূন্য হবে (কোড Upstash/ব্যাকআপে থাকে)।

### বটের নতুন ফিচার (বট > অটোমেশন ট্যাব)
- জয়েন কমান্ড: ঢোকার পর `/login পাস`, `/register পাস পাস` ইত্যাদি স্বয়ংক্রিয়ভাবে পাঠায় (সবার আগে)।
- অটো-রিপ্লাই রুল: চ্যাটে কিছু লিখলে বট উত্তর দেয় (লেখা বা regex, `$1`, `{bot}`, কুলডাউনসহ)।
- নির্দিষ্ট সময় পরপর মেসেজ (অ্যান্টি-AFK)।
- গেম চ্যাট লাইভ দেখা: কনসোল ট্যাবে।
- এগুলো সব স্ক্রিপ্টে কাজ করে, স্ক্রিপ্ট বদলাতে হয় না।

## v2.3: মাল্টি-ফাইল Worker, নতুন টেলিগ্রাম কন্ট্রোল সেন্টার, স্মার্ট ড্যাশবোর্ড

### Workers: একাধিক ফাইল একসাথে
- Worker এখন পুরো প্রজেক্ট: একাধিক ফাইল ও ফোল্ডার। `import { x } from './lib/utils.js'` দিয়ে ফাইলগুলো জোড়া লাগে।
- **ফাইল ম্যানেজার** (Worker > ফাইল ট্যাব): ট্রি ভিউ, এডিটর (Ctrl+S), আপলোড (ফাইল / পুরো ফোল্ডার / ZIP / ড্র্যাগ-ড্রপ), নতুন ফাইল, নাম-পাথ বদল, মুছুন, এন্ট্রি ফাইল বাছা, ZIP ডাউনলোড।
- ZIP আপলোড করলে ভেতরের ফাইলগুলো ফোল্ডারসহ সাজিয়ে রাখা হয় (উপরের একক ফোল্ডার নিজে সরে যায়, `..` ও বিপজ্জনক পাথ আটকানো)।
- **ENV সব ফাইলে কাজ করে**: `env.KEY`, `process.env.KEY`, গ্লোবাল `KEY`। প্রজেক্টে `.env` / `.dev.vars` ফাইল থাকলে সেটিও লোড হয় (প্যানেলের ENV অগ্রাধিকার পায়)। `.env` ফাইল ইমপোর্ট বোতাম আছে।
- **`env.ASSETS`**: `public/`, `static/` বা `assets/` ফোল্ডারের HTML/CSS/JS/ছবি সার্ভ করে (`env.ASSETS.fetch(request)`)। "স্ট্যাটিক সাইট + API" টেমপ্লেট দেখুন।
- **ভার্সন ইতিহাস**: প্রতিটি সফল ডিপ্লয়ে স্ন্যাপশট (সর্বশেষ ৮টি)। ডিপ্লয় ব্যর্থ হলে শেষ ভালো ভার্সন ফেরত আসে, আর ব্যর্থ ফাইলগুলো "ব্যর্থ" ভার্সনে রাখা থাকে (কাজ হারায় না)। যেকোনো ভার্সনে ফেরা যায়।
- **Worker AI** (AI ট্যাব): AI সব ফাইল, লগ, ত্রুটি ও ENV-এর নাম দেখে (মান নয়) কাজ করে। নতুন/বদলানো ফাইলের তালিকা দেখায়, সিনট্যাক্স যাচাই করে, আপনি টিক দিয়ে বাছলে প্রয়োগ ও ডিপ্লয় হয়।
- Rate limit (প্রতি IP/মিনিট), Cron, ক্লোন, ZIP এক্সপোর্ট, এন্ট্রি ফাইল বদল।
- নির্ভরতা: Worker-এ npm install করা যায় না, তবে প্রজেক্টের `node_modules` (express, telegraf, mineflayer) থেকে import চলে।

### Worker বিশ্লেষণ (Cloudflare Workers-এর ধাঁচে)
আজ/গতকাল/৭/৩০ দিন, ত্রুটি (5xx) ও exception/টাইমআউট ভাগ, গড় লেটেন্সি + p50/p95/p99, লেটেন্সি বিন্যাস, গড় CPU সময়, ডাটা ট্রান্সফার, গত ২৪ ঘণ্টা ও ১৪ দিনের চার্ট, **ঘণ্টা × বার হিটম্যাপ**, শীর্ষ এন্ডপয়েন্ট, ডিভাইস/মেথড ভাগ, স্ট্যাটাস কোড, সাম্প্রতিক রিকোয়েস্ট। "আজ" ব্রাউজারের (বা সেটিংসের) টাইমজোনে গোনা হয়।

### স্মার্ট ড্যাশবোর্ড
- **স্মার্ট ইনসাইট**: অফলাইন/বারবার ক্র্যাশ করা বট, মেমরি সীমার কাছে, Worker ত্রুটির হার ও ধীর p95, ট্রাফিক স্পাইক, অব্যবহৃত Worker, সার্ভার ধীর, ডাটা হারানোর ঝুঁকি, অটো-পাসওয়ার্ড সতর্কতা। প্রতিটির পাশে সরাসরি খোলার বোতাম।
- **সিস্টেম স্বাস্থ্য**: RAM, event-loop lag, CPU লোড, ডাটা ফোল্ডার সাইজ, প্রসেস সংখ্যা; সাথে Worker req/min, RAM ও lag-এর লাইভ গ্রাফ।
- **অডিট লগ** (সেটিংস): লগইন, ভুল পাসওয়ার্ড ও সব পরিবর্তনের রেকর্ড।
- **থিম স্টুডিও**: ৬টি অ্যাকসেন্ট (অরোরা, সানসেট, মহাসাগর, পান্না, গোলাপ, মনো), নতুন অ্যানিমেটেড ব্যাকগ্রাউন্ড (অরোরা ফিতা + থ্রিডি পারস্পেক্টিভ গ্রিড + ভাসমান কণা, মাউসে প্যারালাক্স), বন্ধ করার সুইচ। কার্ডে হোভারে ঘূর্ণায়মান আলোর বর্ডার।

### টেলিগ্রাম কন্ট্রোল সেন্টার (সম্পূর্ণ নতুন)
- স্থায়ী মেনু বোতাম (হোম, বট, Workers, অ্যানালিটিক্স, AI, সেটিংস) এবং কমান্ড: `/bots /workers /stats /insights /system /logs নাম /restart নাম /run নাম /stop নাম /say বট মেসেজ /ai প্রশ্ন /help`।
- হোম: বট ও Worker সারাংশ, আজকের রিকোয়েস্ট, স্পার্কলাইন, RAM, ইনসাইট। **🔴 লাইভ** চাপলে কার্ড ২ মিনিট নিজে আপডেট হয় (হোম, বট, Worker, অ্যানালিটিক্স, সিস্টেম)।
- বট: স্বাস্থ্য বার, আপটাইম স্ট্রিপ, লগ, গেম চ্যাট, বিশ্লেষণ, **অটোমেশন (জয়েন কমান্ড, অটো-রিপ্লাই, পিরিয়ডিক)**, স্ক্রিপ্ট (টেমপ্লেট, রোলব্যাক, AI), সেটিংস (অটো-রিস্টার্ট, ক্লোন, মুছুন)। অফলাইন হলে সমস্যা অনুযায়ী সমাধান বোতাম (ব্যান হলে "নাম বদলান", ভার্সন ভুল হলে "ভার্সন সেট")।
- Workers: স্ট্যাটাস, URL, আজকের পরিসংখ্যান; লগ; **টেস্ট (`GET /path`, `POST /api {json}`)**; **ফাইল ব্রাউজ, ফাইল/ZIP আপলোড (সরাসরি টেলিগ্রামে পাঠান), ফাইল পাঠানো/এডিট/মুছা**; **ENV যোগ/বদল/গোপন (আপনার মেসেজ আমি মুছে দিই)**; `.env` ইমপোর্ট; বিশ্লেষণ; ভার্সন ও রোলব্যাক; ডিপ্লয়; ক্লোন; ZIP; Cron ও Rate limit; AI দিয়ে ফাইল বদল + প্রয়োগ।
- যেকোনো `.js/.zip/.env` ফাইল পাঠালে জিজ্ঞেস করে কোথায় রাখবে (Worker, বটের স্ক্রিপ্ট, নতুন Worker)।
- অ্যানালিটিক্স, ইনসাইট, সিস্টেম, **দৈনিক রিপোর্ট (সময় বাছুন)**, নীরব মোড (১/৮/২৪ ঘণ্টা), টাইমজোন, AI মডেল বদল, AI key দেওয়া (মেসেজ মুছে যায়), ব্যাকআপ ফাইল পাঠানো।
- সতর্কতা: বট অফলাইন/ঢুকতে পারছে না, Worker বন্ধ/ক্র্যাশ/ত্রুটির হার বেশি/আবার চালু।

### আরও যা যোগ হয়েছে / ভবিষ্যতের আইডিয়া
যোগ হয়েছে: মাল্টি-ফাইল Worker, ফাইল ম্যানেজার, ZIP, ভার্সন ইতিহাস, ASSETS, .env, Worker AI, rate limit, হিটম্যাপ ও গভীর বিশ্লেষণ, ইনসাইট, সিস্টেম মনিটর, অডিট লগ, থিম স্টুডিও, টেলিগ্রামে সব নিয়ন্ত্রণ।
ভবিষ্যতে: কাস্টম ডোমেইন/সাবডোমেইন রাউটিং, API টোকেন দিয়ে বাইরের স্ক্রিপ্ট থেকে নিয়ন্ত্রণ, একাধিক ব্যবহারকারী ও রোল, সময়সূচি-ভিত্তিক বট কমান্ড, Worker-এ ডাটাবেস (SQLite), বাইরের মনিটর (UptimeRobot) স্ট্যাটাস পেজ।

## v2.5: API টোকেন, ব্যবহারকারী ও রোল, কাস্টম ডোমেইন, Worker-এ SQLite

> **গুরুত্বপূর্ণ:** এই ভার্সনে সেশনের ফরম্যাট বদলেছে। আপগ্রেডের পর একবার আবার লগইন করতে হবে।

### ভূমিকা ও অ্যাক্সেস
- **admin (মালিক):** সব কিছু, সেটিংস, টোকেন ও ব্যবহারকারী। মালিকের পাসওয়ার্ড `ADMIN_PASSWORD` বা ড্যাশবোর্ড থেকে বদলানো পাসওয়ার্ড।
- **operator:** বট ও Worker তৈরি, বদলানো, চালু/বন্ধ। সেটিংস, টোকেন বা ব্যবহারকারী দেখতে বা বদলাতে পারে না।
- **viewer:** শুধু দেখতে পারে, কিছু বদলাতে পারে না।
- ব্যবহারকারীর পাসওয়ার্ড scrypt দিয়ে হ্যাশ করে সংরক্ষিত হয়। মালিকের পাসওয়ার্ড কারও সাথে মেলে না।
- সেটিংস > অ্যাক্সেস কন্ট্রোলে মালিক নতুন ব্যবহারকারী যোগ ও সরাতে পারেন।

### API টোকেন
- সেটিংস > অ্যাক্সেস কন্ট্রোল > নতুন টোকেন। দুটি অনুমতি: **শুধু পড়া** (GET) বা **নিয়ন্ত্রণ** (বট/Worker বদলানো)।
- টোকেন একবারই দেখানো হয়, পরে আর দেখা যায় না। সংরক্ষণ হয় শুধু SHA-256 হ্যাশ।
- ব্যবহার: `curl -H "Authorization: Bearer mcht_..." https://আপনার-হোস্ট/api/state`
- বাতিল করলে সাথে সাথে কাজ বন্ধ হয়। শেষ ব্যবহারের সময় দেখা যায়।
- সর্বোচ্চ ২০টি টোকেন।

### কাস্টম ডোমেইন (Worker)
- Worker > সেটিংস > কাস্টম ডোমেইন, যেমন `api.example.com`।
- **আপনাকে যা করতে হবে:** ডোমেইনের DNS-এ A বা CNAME রেকর্ড আপনার হোস্টের দিকে দিন। যদি Wispbyte বা অন্য হোস্ট সরাসরি IP:পোর্ট দেয়, তাহলে একটি রিভার্স প্রক্সি (Nginx, Caddy, Cloudflare) লাগবে, যা Host হেডার এই প্যানেলে পাঠায়। HTTPS সার্টিফিকেটও প্রক্সিতে হবে। প্যানেল নিজে সার্টিফিকেট বানায় না।
- প্যানেলের নিজের ডোমেইন Worker-এ দেওয়া যাবে না। একই ডোমেইন দুই Worker-এ যাবে না।

### Worker-এ SQLite (env.DB)
- Node 22.5+ এর বিল্ট-ইন `node:sqlite` ব্যবহার করে। ডাটা প্রতি Worker-এর আলাদা `.db` ফাইলে থাকে, Worker মুছলে ফাইলও যায়।
- API (D1-এর মতো): `env.DB.exec(sql)`, `env.DB.prepare(sql).bind(...).all() / .first(col) / .run() / .raw()`, `env.DB.batch([...])`।
- টেমপ্লেট: "SQLite নোট অ্যাপ"।
- সীমা: DB ফাইল বর্তমানে ব্যাকআপে অন্তর্ভুক্ত নয়। Node পুরনো হলে `env.DB` `null` থাকবে।

### টেস্ট ও সীমাবদ্ধতা
- ভূমিকা, টোকেন বাতিল, ডোমেইন যাচাই, ডোমেইন থেকে Worker সার্ভ, SQLite লেখা-পড়া ও মোছা, সব স্বয়ংক্রিয় টেস্টে পাস করেছে।
- এখনো টেলিগ্রাম শুধু মালিকের জন্য খোলা। টেলিগ্রাম থেকে ব্যবহারকারী/টোকেন ব্যবস্থাপনা যোগ হয়নি।
- ব্যবহারকারীর পাসওয়ার্ড কোনো ইমেইল রিকভারির সাথে যুক্ত নেই। ভুলে গেলে মালিক বাতিল করে নতুন দিতে পারেন।
- ব্যাকআপ ফাইলে টোকেন ও ব্যবহারকারীর হ্যাশ থাকে। ব্যাকআপ নিরাপদে রাখুন।

## v2.6: SQLite ব্যাকআপ ও টেলিগ্রাম থেকে অ্যাক্সেস ব্যবস্থাপনা

### SQLite ব্যাকআপ
- ব্যাকআপে এখন প্রতিটি Worker-এর `.db` ফাইলের সুসংগত কপি থাকে (`VACUUM INTO` দিয়ে; Worker চলাকালীনও নিরাপদ)। ফরম্যাট v5।
- রিস্টোর করলে Worker ফিরে আসে এবং তার ডাটাও ফিরে আসে। পরীক্ষায় যোগ করা সারি রিস্টোরের পরে পড়া গেছে।
- পুরনো (v4) ব্যাকআপ রিস্টোর করা যায়, তবে তাতে DB থাকে না।

### টেলিগ্রাম: অ্যাক্সেস ব্যবস্থাপনা (শুধু মালিক)
- ⚙️ সেটিংস > 🔐 অ্যাক্সেস: টোকেন ও ব্যবহারকারীর তালিকা।
- ➕ টোকেন তৈরি: নাম > অনুমতি (শুধু পড়া / নিয়ন্ত্রণ)। টোকেন একবারই দেখানো হয়।
- 🗑 টোকেন বাতিল: নিশ্চিত করে বাতিল।
- 👤 ব্যবহারকারী যোগ: নাম > পাসওয়ার্ড (বার্তা সাথে সাথে মুছে যায়) > ভূমিকা (অপারেটর / শুধু দেখা)।
- মালিকের পাসওয়ার্ড বা অন্য ব্যবহারকারীর পাসওয়ার্ড ব্যবহার করা যায় না।

## v2.7: Worker উন্নতি ও হালকা হোস্ট

### Worker
- **একসাথে একাধিক ফাইল আপলোড:** ফাইল বাছার সময় একসাথে অনেক ফাইল নিলে ৩টি করে সমান্তরালে যায়, প্রগ্রেস দেখায়। ফোল্ডার ও ZIPও চলে।
- **ডিপ্লয়ের আগে যাচাই (যাচাই বাটন ও স্বয়ংক্রিয়):** সিনট্যাক্স, না-থাকা ফাইলের ইমপোর্ট, ব্যবহৃত কিন্তু সেট-না-থাকা ENV, node_modules-এ না থাকা প্যাকেজ। ভুল থাকলে প্রসেস শুরুই হয় না, তাই ব্যর্থ ডিপ্লয় দ্রুত ধরা পড়ে।
- **ভার্সন তুলনা:** প্রতিটি ভার্সনের সাথে বর্তমান কোডের তুলনা। কোন ফাইল নতুন, বদলেছে বা বাদ গেছে, কত লাইন যোগ/বাদ, এবং ফাইল খুললে লাইনের রঙিন পার্থক্য।
- **সব Worker একসাথে চালু/বন্ধ:** তালিকা পেজের উপরে বোতাম।
- **প্রতি Worker-এর একসাথের অনুরোধ সীমা** (৫–৫০০, ডিফল্ট ৫০): সেটিংসে বদলানো যায়। সীমা ছাড়ালে 429 আসে।
- **সেভ করা টেস্ট রিকোয়েস্ট:** টেস্ট ট্যাবে রিকোয়েস্ট সেভ করে পরে এক ক্লিকে লোড করা যায় (ব্রাউজারে সংরক্ষিত)।

### হোস্টের চাপ কমানো (ব্রাউজারে সংরক্ষণ)
- **AI চ্যাটের ইতিহাস এখন আপনার ব্রাউজারে থাকে** (বট ও Worker দুটোতেই)। প্রতিটি প্রশ্নের সাথে শেষ কয়েকটি বার্তা পাঠানো হয়, সার্ভার সেগুলো জমা রাখে না। টেলিগ্রামের AI মেমরি আগের মতোই সার্ভারে থাকে।
- **একই অবস্থায় অপ্রয়োজনীয় রি-রেন্ডার বন্ধ:** প্যানেল নতুন তথ্য না পেলে স্ক্রিন নতুন করে আঁকে না।
- **বিশ্লেষণের ক্যাশ:** নতুন অনুরোধ না এলে পরিসংখ্যান গণনা বারবার হয় না। সর্বোচ্চ এক মিনিট পুরনো তথ্য দেখাতে পারে (দিন/ঘণ্টার সীমার জন্য)।

### সীমাবদ্ধতা
- "দ্রুত রেসপন্স" ও "মাল্টিটাস্ক" বলতে এখানে যা আছে: ক্যাশ, সমান্তরাল আপলোড, Worker-প্রতি সীমা। প্রতিটি Worker আগের মতোই আলাদা প্রসেসে চলে। এর চেয়ে বেশি দ্রুততা মাপা হয়নি।
- ড্যাশবোর্ডের নতুন দৃশ্যগত রিডিজাইন এই ধাপে করা হয়নি। আগের ধাপের ডিজাইনই রয়েছে।
- ব্রাউজারের ইতিহাস শুধু ওই ব্রাউজারে থাকে। ফোন বদলালে বা ক্যাশ মুছলে তা হারাবে।
- যাচাইয়ের প্যাকেজ-সনাক্তকরণ সরল: `node_modules` ফোল্ডার দেখে, npm রেজিস্ট্রি দেখে না।

## v2.8: Google Drive ব্যাকআপ, কথায় নির্দেশ, লাইভ আপডেট, PWA ও আরও

### Google Drive ব্যাকআপ (সেটিংস > Google Drive ব্যাকআপ)
ধাপে ধাপে:
1. Google Cloud Console-এ একটি OAuth ক্লায়েন্ট বানান: **Application type: Web application**।
2. প্যানেলে Client ID ও Client Secret দিন, "লগইন লিংক বানান" চাপুন।
3. প্যানেলে দেখানো **Redirect URI** (`https://আপনার-হোস্ট/api/gdrive/callback`) Console-এর "Authorized redirect URIs"-এ যোগ করুন।
4. লিংক খুলে Google-এ লগইন করুন। ফিরে এলেই সংযুক্ত হবে এবং Drive-এ **MC Host Backups** ফোল্ডার তৈরি হবে।

- ব্যাকআপে সব বট, Worker-এর ফাইল, স্ক্রিপ্ট, SQLite ডাটাবেস থাকে। **Google Client Secret ও refresh token ব্যাকআপে থাকে না।**
- অ্যাপ শুধু নিজের তৈরি ফাইলে প্রবেশ করতে পারে (`drive.file` স্কোপ)।
- স্বয়ংক্রিয় ব্যাকআপ: বন্ধ / ১ / ৬ / ১২ / ২৪ ঘণ্টা। এছাড়া প্রতিবার অ্যাডমিন লগইনে শেষ ব্যাকআপ ৩০ মিনিটের বেশি পুরনো হলে নতুন ব্যাকআপ নেওয়া হয়।
- সর্বশেষ N টি ব্যাকআপ রাখা হয় (৩–৬০), পুরনোগুলো নিজে থেকে মুছে যায়।
- তালিকা থেকে যেকোনো ব্যাকআপে ফেরা যায়; ফেরার আগে বর্তমান অবস্থার নতুন ব্যাকআপ নেওয়া হয়।
- **সতর্কতা:** Google OAuth কনসেন্ট স্ক্রিনকে "Testing" অবস্থায় রাখলে refresh token প্রায় ৭ দিনে মেয়াদোত্তীর্ণ হয়। প্রোডাকশনে প্রকাশ (Publish) করুন।
- **সতর্কতা:** ব্যাকআপে Worker-এর ENV ভ্যালু (আপনার গোপন মানও) থাকে। Drive ফোল্ডার নিরাপদ রাখুন।

## v2.9: স্মার্ট অটোমেশন, Worker টুলস, ইন্টিগ্রেশন ও রিপোর্ট

### Worker
- **টেস্ট স্যুট (`tests.json`):** প্রজেক্টে এই ফাইল রাখলে "টেস্ট চালাও" বোতাম চলে। ফরম্যাট:

- **কঠোর ডিপ্লয় (strict tests):** সেটিংসে চালু করলে ডিপ্লয়ের পর টেস্ট চলে। একটিও ব্যর্থ হলে আগের ভালো ভার্সনে ফিরে যায়।

- **NOTIFY:** Worker কোডে `await env.NOTIFY("বার্তা")` লিখলে `NOTIFY_URL` ENV-এ দেওয়া Discord, Slack বা যেকোনো ওয়েবহুকে বার্তা যায়।
- **বারবার একই ত্রুটি:** একই ত্রুটি তিনবার বা বেশি হলে ইনসাইটে সতর্কতা।

### অটোমেশন ও AI
- **কথায় নির্দেশ আরও বুদ্ধিমান:** "সবচেয়ে বেশি রিকোয়েস্ট কোন Worker?", "সবচেয়ে ধীর কোনটি?" প্রশ্নের উত্তর পরিসংখ্যান থেকে। AI ছাড়াও কাজ করে।
- **AI কোড রিভিউ** (আগের ধাপ থেকে) এখন আরও পরিষ্কার রায় দেয়।

### ইন্টিগ্রেশন ও ওয়েবহুক
- **ইনবাউন্ড হুক (সেটিংস > ওয়েবহুক):** প্রতিটি হুকের একটি URL ও সিক্রেট আছে। কাজ: Worker রিস্টার্ট/চালু/বন্ধ, বট রিস্টার্ট (একটি বা সব), বা Drive-এ ব্যাকআপ।
  - GitHub-এ Webhook হিসেবে বসান, Content type `application/json`, Secret হিসেবে প্যানেলের সিক্রেট দিন। ডেলিভারির সিগনেচার (`X-Hub-Signature-256`) যাচাই হয়। ভুল সিগনেচারে 401।
  - অন্য সেবায় `x-mch-secret` হেডারে সিক্রেট পাঠানো যায়।
- **OpenAPI:** `/api/openapi.json` (লগইন লাগে) থেকে প্রধান এন্ডপয়েন্টের বর্ণনা।
- **Discord/Slack:** সতর্কতা ওয়েবহুকে যায় (আগের ধাপ থেকে)।

### পর্যবেক্ষণ ও রিপোর্ট
- **SLA ও সম্পদ রিপোর্ট (CSV):** ৭ বা ৩০ দিনের। প্রতিটি বটের আপটাইম %, সেশন, ক্র্যাশ; প্রতিটি Worker-এর অনুরোধ, 5xx, ত্রুটি %, গড় সময়, CPU ms/অনুরোধ, ডাটা, বাজেট অবস্থা।
- **Google Drive-এ রিপোর্ট:** "Drive-এ পাঠান" বোতাম বা প্রতি সোমবার সকাল ৯টায় স্বয়ংক্রিয়। রিপোর্টগুলো ব্যাকআপ ফোল্ডার থেকে আলাদা **MC Host Reports** ফোল্ডারে যায়। Drive সংযুক্ত না থাকলে এটি কাজ করে না।
