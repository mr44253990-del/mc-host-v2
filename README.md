# MC Host v2.3

মাইনক্রাফট (mineflayer) বট হোস্ট করার প্যানেল: ওয়েব ড্যাশবোর্ড + টেলিগ্রাম কন্ট্রোল + Mistral AI সহায়ক।
Wispbyte, Render বা যেকোনো Node.js হোস্টে চলে।

## Wispbyte-এ চালু করার ধাপ
1. Wispbyte client panel-এ আপনার সার্ভার খুলুন এবং সার্ভার পেজে দেখানো **পোর্ট** (যেমন 11336) নোট করুন।
2. এই ফোল্ডারের সব ফাইল সার্ভারে আপলোড করুন (বা Git repo থেকে নিন)। `node_modules` ও `data` আপলোড করবেন না।
3. Startup/Main file: `index.js` (অথবা কমান্ড `npm start`)। Node 18+ লাগবে। প্রথমবার `npm install` চালান।
4. Environment/Variables-এ দিন: `ADMIN_PASSWORD`, প্রয়োজনে `PORT` (প্যানেলে দেখানো পোর্ট), `MISTRAL_API_KEY`, `TELEGRAM_BOT_TOKEN`, `OWNER_ID`।
5. সার্ভার চালু করুন। কনসোলে `চালু: http://0.0.0.0:<পোর্ট>` দেখলে ঠিক আছে। Wispbyte পেজ রিফ্রেশ দিলে "running" দেখাবে।
6. ব্রাউজারে Wispbyte-এর দেওয়া ঠিকানা (IP:পোর্ট) খুলে পাসওয়ার্ড দিয়ে ঢুকুন।

পোর্ট নিয়ম: `PORT` > `SERVER_PORT` > `APP_PORT` > ডিফল্ট 11336। সার্ভার সবসময় `0.0.0.0`-এ শোনে (127.0.0.1 নয়)।
`ADMIN_PASSWORD` না দিলে প্রথমবার কনসোলে একটি পাসওয়ার্ড ছাপা হয়।

## Render-এ
`render.yaml` ব্যবহার করুন। ফ্রি প্ল্যানে ১৫ মিনিট নিষ্ক্রিয়তায় ঘুমিয়ে যায়: UptimeRobot দিয়ে `/healthz` প্রতি ৫ মিনিটে পিং করুন।
ফাইল মুছে গেলে বট ফেরাতে Upstash Redis (`UPSTASH_REDIS_REST_URL` / `_TOKEN`) দিন।

## Mistral AI
ড্যাশবোর্ড > সেটিংস থেকে API key দিন ও মডেল বাছুন (লিস্ট লাইভ লোড হয়)। কী করে:
- টেলিগ্রামে বটের পেজ > "AI দিয়ে স্ক্রিপ্ট আপডেট": সাধারণ ভাষায় বলুন, AI বটের লগ, বর্তমান স্ক্রিপ্ট ও আগের কথা মনে রেখে নতুন স্ক্রিপ্ট দেয়।
- কোড সিনট্যাক্স যাচাই হয়, তারপর "প্রয়োগ করুন" চাপলে সেভ হয়ে বট রিস্টার্ট হয় (আগের সংস্করণ রোলব্যাকে থাকে)।
- অফলাইন নোটিফিকেশনে "AI দিয়ে বিশ্লেষণ" বোতাম আছে। ওয়েব ড্যাশবোর্ডের AI পেজেও একই চ্যাট।
- AI মেমরি: প্রতি বটের আলাদা কথোপকথন ও সারাংশ নোট। মুছতে "মেমরি মুছুন"।

## টেলিগ্রাম
টোকেন ড্যাশবোর্ডের টেলিগ্রাম পেজ বা `TELEGRAM_BOT_TOKEN` env-এ দিন, তারপর বটকে /start দিন। প্রথম যিনি /start দেবেন তিনি মালিক (বা `OWNER_ID` দিন)।

## v2.2: Workers পেজ (Cloudflare Workers-এর মতো) ও বটের নতুন ফিচার
### Workers
- নতুন "Workers" পেজ: worker.js আপলোড (বা টেমপ্লেট/পেস্ট) > ডিপ্লয় > পাবলিক URL `https://আপনার-হোস্ট/w/<নাম>/...` (লগইন লাগে না)।
- ফরম্যাট: `export default { async fetch(request, env, ctx) {...}, async scheduled(event, env, ctx) {...} }` অথবা `addEventListener('fetch', e => e.respondWith(...))`। CommonJS (`module.exports = { fetch }`) ও চলে।
- ENV ভেরিয়েবল: কোডে `env.KEY` (বা `process.env.KEY`)। "গোপন" দিলে ভ্যালু আর প্যানেলে দেখা যায় না। বদলালে Worker নিজে রিস্টার্ট হয়।
- `env.KV`: সরল স্থায়ী key-value (get/put/delete/list, expirationTtl সহ, সর্বোচ্চ ৫০০০ key)।
- Cron: সেটিংসে মিনিট দিলে `scheduled()` চলে।
- ড্যাশবোর্ড: আজকের রিকোয়েস্ট, গতকাল, ৭/৩০ দিন, ত্রুটি (5xx) ও ত্রুটির হার, গড় লেটেন্সি, p50/p95, গত ২৪ ঘণ্টা ও ১৪ দিনের চার্ট, স্ট্যাটাস কোড ভাগ, সাম্প্রতিক রিকোয়েস্ট তালিকা। "আজ" আপনার ব্রাউজারের টাইমজোন অনুযায়ী গোনা হয়।
- নিরাপদ ডিপ্লয়: নতুন কোড লোড না হলে আগের কোডই চালু থাকে, আর "আগের সংস্করণ" বোতামে রোলব্যাক যায়।
- টেস্ট ট্যাব (মেথড, হেডার, বডি পাঠিয়ে উত্তর দেখুন), লাইভ console লগ, ক্র্যাশ হলে অটো-রিস্টার্ট, ৩০ সেকেন্ডে উত্তর না দিলে 504।
- প্রতিটি Worker আলাদা প্রসেস (মেমরি `WORKER_HEAP_MB`, ডিফল্ট 128)। সীমা `MAX_WORKERS` (১০)। রিকোয়েস্ট বডি ও রেসপন্স যথাক্রমে ১MB ও ৫MB পর্যন্ত। Worker কোডকে বিশ্বাসযোগ্য ধরা হয় (বটের স্ক্রিপ্টের মতোই), তাই শুধু নিজের কোড আপলোড করুন।
- স্ট্যাটাস `data/workers/` ফোল্ডারে থাকে। হোস্টের ফাইল মুছে গেলে কাউন্টার শূন্য হবে (কোড Upstash/ব্যাকআপে থাকে)।

### বটের নতুন ফিচার (বট > অটোমেশন ট্যাব)
- জয়েন কমান্ড: ঢোকার পর `/login পাস`, `/register পাস পাস` ইত্যাদি স্বয়ংক্রিয়ভাবে পাঠায় (সবার আগে)।
- অটো-রিপ্লাই রুল: চ্যাটে কিছু লিখলে বট উত্তর দেয় (লেখা বা regex, `$1`, `{bot}`, কুলডাউনসহ)।
- নির্দিষ্ট সময় পরপর মেসেজ (অ্যান্টি-AFK)।
- গেম চ্যাট লাইভ দেখা: কনসোল ট্যাবে।
- এগুলো সব স্ক্রিপ্টে কাজ করে, স্ক্রিপ্ট বদলাতে হয় না।

## v2.3: মাল্টি-ফাইল Worker, নতুন টেলিগ্রাম কন্ট্রোল সেন্টার, স্মার্ট ড্যাশবোর্ড

### Workers: একাধিক ফাইল একসাথে
- Worker এখন পুরো প্রজেক্ট: একাধিক ফাইল ও ফোল্ডার। `import { x } from './lib/utils.js'` দিয়ে ফাইলগুলো জোড়া লাগে।
- **ফাইল ম্যানেজার** (Worker > ফাইল ট্যাব): ট্রি ভিউ, এডিটর (Ctrl+S), আপলোড (ফাইল / পুরো ফোল্ডার / ZIP / ড্র্যাগ-ড্রপ), নতুন ফাইল, নাম-পাথ বদল, মুছুন, এন্ট্রি ফাইল বাছা, ZIP ডাউনলোড।
- ZIP আপলোড করলে ভেতরের ফাইলগুলো ফোল্ডারসহ সাজিয়ে রাখা হয় (উপরের একক ফোল্ডার নিজে সরে যায়, `..` ও বিপজ্জনক পাথ আটকানো)।
- **ENV সব ফাইলে কাজ করে**: `env.KEY`, `process.env.KEY`, গ্লোবাল `KEY`। প্রজেক্টে `.env` / `.dev.vars` ফাইল থাকলে সেটিও লোড হয় (প্যানেলের ENV অগ্রাধিকার পায়)। `.env` ফাইল ইমপোর্ট বোতাম আছে।
- **`env.ASSETS`**: `public/`, `static/` বা `assets/` ফোল্ডারের HTML/CSS/JS/ছবি সার্ভ করে (`env.ASSETS.fetch(request)`)। "স্ট্যাটিক সাইট + API" টেমপ্লেট দেখুন।
- **ভার্সন ইতিহাস**: প্রতিটি সফল ডিপ্লয়ে স্ন্যাপশট (সর্বশেষ ৮টি)। ডিপ্লয় ব্যর্থ হলে শেষ ভালো ভার্সন ফেরত আসে, আর ব্যর্থ ফাইলগুলো "ব্যর্থ" ভার্সনে রাখা থাকে (কাজ হারায় না)। যেকোনো ভার্সনে ফেরা যায়।
- **Worker AI** (AI ট্যাব): AI সব ফাইল, লগ, ত্রুটি ও ENV-এর নাম দেখে (মান নয়) কাজ করে। নতুন/বদলানো ফাইলের তালিকা দেখায়, সিনট্যাক্স যাচাই করে, আপনি টিক দিয়ে বাছলে প্রয়োগ ও ডিপ্লয় হয়।
- Rate limit (প্রতি IP/মিনিট), Cron, ক্লোন, ZIP এক্সপোর্ট, এন্ট্রি ফাইল বদল।
- নির্ভরতা: Worker-এ npm install করা যায় না, তবে প্রজেক্টের `node_modules` (express, telegraf, mineflayer) থেকে import চলে।

### Worker বিশ্লেষণ (Cloudflare Workers-এর ধাঁচে)
আজ/গতকাল/৭/৩০ দিন, ত্রুটি (5xx) ও exception/টাইমআউট ভাগ, গড় লেটেন্সি + p50/p95/p99, লেটেন্সি বিন্যাস, গড় CPU সময়, ডাটা ট্রান্সফার, গত ২৪ ঘণ্টা ও ১৪ দিনের চার্ট, **ঘণ্টা × বার হিটম্যাপ**, শীর্ষ এন্ডপয়েন্ট, ডিভাইস/মেথড ভাগ, স্ট্যাটাস কোড, সাম্প্রতিক রিকোয়েস্ট। "আজ" ব্রাউজারের (বা সেটিংসের) টাইমজোনে গোনা হয়।

### স্মার্ট ড্যাশবোর্ড
- **স্মার্ট ইনসাইট**: অফলাইন/বারবার ক্র্যাশ করা বট, মেমরি সীমার কাছে, Worker ত্রুটির হার ও ধীর p95, ট্রাফিক স্পাইক, অব্যবহৃত Worker, সার্ভার ধীর, ডাটা হারানোর ঝুঁকি, অটো-পাসওয়ার্ড সতর্কতা। প্রতিটির পাশে সরাসরি খোলার বোতাম।
- **সিস্টেম স্বাস্থ্য**: RAM, event-loop lag, CPU লোড, ডাটা ফোল্ডার সাইজ, প্রসেস সংখ্যা; সাথে Worker req/min, RAM ও lag-এর লাইভ গ্রাফ।
- **অডিট লগ** (সেটিংস): লগইন, ভুল পাসওয়ার্ড ও সব পরিবর্তনের রেকর্ড।
- **থিম স্টুডিও**: ৬টি অ্যাকসেন্ট (অরোরা, সানসেট, মহাসাগর, পান্না, গোলাপ, মনো), নতুন অ্যানিমেটেড ব্যাকগ্রাউন্ড (অরোরা ফিতা + থ্রিডি পারস্পেক্টিভ গ্রিড + ভাসমান কণা, মাউসে প্যারালাক্স), বন্ধ করার সুইচ। কার্ডে হোভারে ঘূর্ণায়মান আলোর বর্ডার।

### টেলিগ্রাম কন্ট্রোল সেন্টার (সম্পূর্ণ নতুন)
- স্থায়ী মেনু বোতাম (হোম, বট, Workers, অ্যানালিটিক্স, AI, সেটিংস) এবং কমান্ড: `/bots /workers /stats /insights /system /logs নাম /restart নাম /run নাম /stop নাম /say বট মেসেজ /ai প্রশ্ন /help`।
- হোম: বট ও Worker সারাংশ, আজকের রিকোয়েস্ট, স্পার্কলাইন, RAM, ইনসাইট। **🔴 লাইভ** চাপলে কার্ড ২ মিনিট নিজে আপডেট হয় (হোম, বট, Worker, অ্যানালিটিক্স, সিস্টেম)।
- বট: স্বাস্থ্য বার, আপটাইম স্ট্রিপ, লগ, গেম চ্যাট, বিশ্লেষণ, **অটোমেশন (জয়েন কমান্ড, অটো-রিপ্লাই, পিরিয়ডিক)**, স্ক্রিপ্ট (টেমপ্লেট, রোলব্যাক, AI), সেটিংস (অটো-রিস্টার্ট, ক্লোন, মুছুন)। অফলাইন হলে সমস্যা অনুযায়ী সমাধান বোতাম (ব্যান হলে "নাম বদলান", ভার্সন ভুল হলে "ভার্সন সেট")।
- Workers: স্ট্যাটাস, URL, আজকের পরিসংখ্যান; লগ; **টেস্ট (`GET /path`, `POST /api {json}`)**; **ফাইল ব্রাউজ, ফাইল/ZIP আপলোড (সরাসরি টেলিগ্রামে পাঠান), ফাইল পাঠানো/এডিট/মুছা**; **ENV যোগ/বদল/গোপন (আপনার মেসেজ আমি মুছে দিই)**; `.env` ইমপোর্ট; বিশ্লেষণ; ভার্সন ও রোলব্যাক; ডিপ্লয়; ক্লোন; ZIP; Cron ও Rate limit; AI দিয়ে ফাইল বদল + প্রয়োগ।
- যেকোনো `.js/.zip/.env` ফাইল পাঠালে জিজ্ঞেস করে কোথায় রাখবে (Worker, বটের স্ক্রিপ্ট, নতুন Worker)।
- অ্যানালিটিক্স, ইনসাইট, সিস্টেম, **দৈনিক রিপোর্ট (সময় বাছুন)**, নীরব মোড (১/৮/২৪ ঘণ্টা), টাইমজোন, AI মডেল বদল, AI key দেওয়া (মেসেজ মুছে যায়), ব্যাকআপ ফাইল পাঠানো।
- সতর্কতা: বট অফলাইন/ঢুকতে পারছে না, Worker বন্ধ/ক্র্যাশ/ত্রুটির হার বেশি/আবার চালু।
