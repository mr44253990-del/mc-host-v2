# MC Host v2

মাইনক্রাফট (mineflayer) বট হোস্ট করার প্যানেল: ওয়েব ড্যাশবোর্ড + টেলিগ্রাম কন্ট্রোল + Mistral AI সহায়ক।
Wispbyte, Render বা যেকোনো Node.js হোস্টে চলে।

## Wispbyte-এ চালু করার ধাপ
1. Wispbyte client panel-এ আপনার সার্ভার খুলুন এবং সার্ভার পেজে দেখানো **পোর্ট** (যেমন 11336) নোট করুন।
2. এই ফোল্ডারের সব ফাইল সার্ভারে আপলোড করুন (বা Git repo থেকে নিন)। `node_modules` ও `data` আপলোড করবেন না।
3. Startup/Main file: `index.js` (অথবা কমান্ড `npm start`)। Node 18+ লাগবে। প্রথমবার `npm install` চালান।
4. Environment/Variables-এ দিন: `ADMIN_PASSWORD`, প্রয়োজনে `PORT` (প্যানেলে দেখানো পোর্ট), `MISTRAL_API_KEY`, `TELEGRAM_BOT_TOKEN`, `OWNER_ID`।
5. সার্ভার চালু করুন। কনসোলে `চালু: http://0.0.0.0:<পোর্ট>` দেখলে ঠিক আছে। Wispbyte পেজ রিফ্রেশ দিলে "running" দেখাবে।
6. ব্রাউজারে Wispbyte-এর দেওয়া ঠিকানা (IP:পোর্ট) খুলে পাসওয়ার্ড দিয়ে ঢুকুন।

পোর্ট নিয়ম: `PORT` > `SERVER_PORT` > `APP_PORT` > ডিফল্ট 11336। সার্ভার সবসময় `0.0.0.0`-এ শোনে (127.0.0.1 নয়)।
`ADMIN_PASSWORD` না দিলে প্রথমবার কনসোলে একটি পাসওয়ার্ড ছাপা হয়।

## Render-এ
`render.yaml` ব্যবহার করুন। ফ্রি প্ল্যানে ১৫ মিনিট নিষ্ক্রিয়তায় ঘুমিয়ে যায়: UptimeRobot দিয়ে `/healthz` প্রতি ৫ মিনিটে পিং করুন।
ফাইল মুছে গেলে বট ফেরাতে Upstash Redis (`UPSTASH_REDIS_REST_URL` / `_TOKEN`) দিন।

## Mistral AI
ড্যাশবোর্ড > সেটিংস থেকে API key দিন ও মডেল বাছুন (লিস্ট লাইভ লোড হয়)। কী করে:
- টেলিগ্রামে বটের পেজ > "AI দিয়ে স্ক্রিপ্ট আপডেট": সাধারণ ভাষায় বলুন, AI বটের লগ, বর্তমান স্ক্রিপ্ট ও আগের কথা মনে রেখে নতুন স্ক্রিপ্ট দেয়।
- কোড সিনট্যাক্স যাচাই হয়, তারপর "প্রয়োগ করুন" চাপলে সেভ হয়ে বট রিস্টার্ট হয় (আগের সংস্করণ রোলব্যাকে থাকে)।
- অফলাইন নোটিফিকেশনে "AI দিয়ে বিশ্লেষণ" বোতাম আছে। ওয়েব ড্যাশবোর্ডের AI পেজেও একই চ্যাট।
- AI মেমরি: প্রতি বটের আলাদা কথোপকথন ও সারাংশ নোট। মুছতে "মেমরি মুছুন"।

## টেলিগ্রাম
টোকেন ড্যাশবোর্ডের টেলিগ্রাম পেজ বা `TELEGRAM_BOT_TOKEN` env-এ দিন, তারপর বটকে /start দিন। প্রথম যিনি /start দেবেন তিনি মালিক (বা `OWNER_ID` দিন)।

## নতুন কী (v2)
- লিকুইড গ্লাস থ্রিডি ডিজাইন, ডার্ক/লাইট থিম, কোনো ইমোজি নেই (আইকন কোডে আঁকা)
- ড্যাশবোর্ড: লাইভ গ্রাফ, বট কার্ডে স্বাস্থ্য স্কোর রিং ও হটবার, বিশ্লেষণ পেজ (সমস্যার ধরন, সময়রেখা)
- স্মার্ট রিকানেক্ট: জিটারসহ এক্সপোনেনশিয়াল ব্যাকঅফ, ব্যান/ভার্সন/স্ক্রিপ্ট ত্রুটিতে ধীর রিট্রাই, ৬০ সেকেন্ড নীরব থাকলে ওয়াচডগ রিস্টার্ট
- গেমে চ্যাট পাঠানো, বট-প্রতি পরিসংখ্যান (সেশন, ক্র্যাশ, আপটাইম)
- সীমা: `MAX_MC_BOTS` (৫), `MAX_TG_BOTS` (৩), বট-প্রতি RAM `MC_BOT_HEAP_MB` (192)
