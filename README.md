# MC Host v3 — শুধু Workers

এই সংস্করণে বট, Telegram ও অন্য সব অংশ বাদ দেওয়া হয়েছে। থাকে শুধু **Workers**:
ফাইল আপলোড, চালানো, মনিটর করা, ডাটাবেস দেখা, ব্যাকআপ, এবং RAM/CPU-র হিসাব।

## কেন কম RAM লাগে
- Telegram ও Minecraft লাইব্রেরি আর লোড হয় না।
- **ঘুমন্ত Worker:** নিষ্ক্রিয় থাকলে প্রসেস বন্ধ হয়ে যায় (RAM শূন্য)। প্রথম রিকোয়েস্টে জেগে ওঠে। সময় ঠিক করেন প্রতি Worker-এ "ঘুমাবে নিষ্ক্রিয় হলে" সেটিংসে।
- প্রতি Worker-এর আলাদা RAM সীমা (32–512MB, ডিফল্ট 64MB)। ড্যাশবোর্ডে প্রতিটির RAM দেখা যায়।
- কোনো বিশেষ Worker সবসময় জাগা রাখতে চাইলে idle 0 দিন, বা Cron চালু করুন (Cron থাকলে ঘুমায় না)।

## দ্রুত শুরু (Wispbyte)
1. Wispbyte-এ সার্ভারের পোর্ট নোট করুন (যেমন 11336)।
2. ফাইলগুলো আপলোড করুন (`node_modules` ও `data` ছাড়া)। Main file: `index.js`।
3. Variables-এ `ADMIN_PASSWORD` দিন। প্রয়োজনে `PORT` বা `SERVER_PORT`।
4. `npm install` চালান, তারপর সার্ভার চালু করুন। কনসোলে `চালু: http://0.0.0.0:<পোর্ট>` দেখলে ঠিক আছে।
5. ব্রাউজারে Wispbyte-এর ঠিকানা খুলে পাসওয়ার্ড দিন।

Node 18+ লাগবে। SQLite-এর জন্য Node 22.5+ (না থাকলে শুধু `env.DB` বন্ধ থাকে, বাকি সব চলে)।

## Worker তৈরি
- টেমপ্লেট থেকে (Hello, JSON API, KV কাউন্টার, রিভার্স প্রক্সি, মাল্টি-ফাইল, স্ট্যাটিক সাইট, SQLite নোট)।
- নিজের ফাইল বা ফোল্ডার আপলোড (একসাথে কয়েকটি), অথবা ZIP।
- URL: `https://আপনার-হোস্ট/w/<নাম>/...` (লগইন লাগে না)। কাস্টম ডোমেইনও দেওয়া যায় (DNS ও প্রক্সি আপনাকে ঠিক করতে হবে)।

Worker-এর ভেতরে:
- `env.KEY` বা `process.env.KEY`: ENV (গোপন মান দেখা যায় না)। প্রজেক্টে `.env` ফাইল থাকলে সেটিও লোড হয়।
- `env.KV`: স্থায়ী key-value।
- `env.DB`: SQLite (D1-এর মতো API)। ডাটাবেস ট্যাবে শুধু পড়া যায়।
- `env.CACHE`: মেমরিতে ছোট ক্যাশ (`get`, `put(k,v,{ttl})`, `delete`)। ঘুমালে খালি হয়।
- `env.ASSETS`: `public/` ফোল্ডারের স্ট্যাটিক ফাইল।
- `env.NOTIFY("বার্তা")`: `NOTIFY_URL` ENV-এর ওয়েবহুকে বার্তা (Discord/Slack)।

## টেস্ট ও নিরাপদ ডিপ্লয়
- প্রজেক্টে `tests.json` রাখুন: `[{"name":"home","method":"GET","path":"/","expect":{"status":200,"includes":"ok","maxMs":500}}]`।
- "কঠোর ডিপ্লয়" চালু করলে ডিপ্লয়ের পর টেস্ট চলে; ব্যর্থ হলে আগের ভার্সনে ফিরে যায়।
- ভার্সন ইতিহাস, তুলনা (কোন ফাইল বদলেছে, +/− লাইন), এক ক্লিকে ফেরা।
- AI রিভিউ (Mistral key দিলে): নিরাপত্তা ও বাগের রিপোর্ট।

## মনিটরিং ও বাজেট
- প্রতি Worker: RAM, আজকের রিকোয়েস্ট, ত্রুটি, গড় ও p95 সময়, CPU ms/অনুরোধ, ডাটা।
- পারফরম্যান্স বাজেট: সর্বোচ্চ p95 ও ত্রুটি %। সীমা পেরোলে সতর্কতা।
- দৈনিক রিকোয়েস্ট সীমা (সেটিংস): পেরোলে 429।
- Concurrency সীমা (5–500)।
- CSV রিপোর্ট (৭/৩০ দিন), Drive-এ পাঠানো বা প্রতি সোমবার স্বয়ংক্রিয়।

## ব্যাকআপ
- JSON ডাউনলোড/ফেরত (সব Worker, ফাইল, ENV, SQLite, হুক)।
- Google Drive: সেটিংস থেকে সংযুক্ত করুন। ফোল্ডার "MC Host Backups"। স্বয়ংক্রিয় ব্যাকআপ (১/৬/১২/২৪ ঘণ্টা), শেষ N টি রাখা হয়। রিপোর্ট যায় আলাদা "MC Host Reports" ফোল্ডারে।
- Drive-এর refresh token ও Client Secret ব্যাকআপে থাকে না। Worker-এর ENV মান থাকে, তাই Drive ফোল্ডার নিরাপদ রাখুন।
- OAuth কনসেন্ট স্ক্রিন "Testing" অবস্থায় থাকলে refresh token প্রায় ৭ দিনে মেয়াদোত্তীর্ণ হয়। প্রকাশ (Publish) করুন।

## ওয়েবহুক ও API
- হুক: Worker রিস্টার্ট/চালু/বন্ধ, অথবা Drive ব্যাকআপ। GitHub-এ Secret হিসেবে প্যানেলের সিক্রেট দিন; `X-Hub-Signature-256` যাচাই হয়।
- API টোকেন: `Authorization: Bearer mcht_...`। "শুধু পড়া" বা "নিয়ন্ত্রণ"। সেটিংস, টোকেন ও ব্যাকআপ শুধু মালিক।
- OpenAPI: `/api/openapi.json` (লগইন লাগে)।

## ENV ভেরিয়েবল
| নাম | কাজ | ডিফল্ট |
|---|---|---|
| `ADMIN_PASSWORD` | প্যানেলের পাসওয়ার্ড | অটো (কনসোলে দেখায়) |
| `PORT` / `SERVER_PORT` | পোর্ট | 11336 |
| `MAX_WORKERS` | সর্বোচ্চ Worker | 20 |
| `WORKER_HEAP_MB` | Worker-এর ডিফল্ট RAM সীমা | 64 |
| `MISTRAL_API_KEY` | AI (ঐচ্ছিক) | — |
| `DATA_DIR` | ডাটা ফোল্ডার | ./data |

## আগের সংস্করণ থেকে
- পুরনো বট-ডাটা ও Telegram সেটিং নতুন সংস্করণে কাজ করবে না (ইচ্ছাকৃতভাবে বাদ)।
- আপগ্রেডের পর একবার আবার লগইন করুন।
- পুরনো Worker-ভিত্তিক ব্যাকআপ (v4 থেকে নতুন) রিস্টোর করা যায়; বট-সংক্রান্ত অংশ উপেক্ষা হয়।

## সীমাবদ্ধতা
- Worker কোড সার্ভারে সরাসরি চলে। শুধু বিশ্বস্ত কোড আপলোড করুন।
- `npm install` Worker-এর ভেতরে হয় না; প্রজেক্টের `node_modules` থেকে import চলে।
- ক্যানারি ডিপ্লয়, WebSocket, প্লাগইন, Workflow এখনো নেই।
- Wispbyte-এর আসল পরিবেশে প্রথমবার চালানোর সময় যাচাই হয়নি।
